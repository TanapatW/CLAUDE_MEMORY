# Initialize Project Memory

Scan the current project and populate CLAUDE.md with:

1. **Project Overview**: Read package.json (or equivalent) to identify the project name, description, and tech stack
2. **Directory Structure**: List the top-level directories and describe their purpose
3. **Commands**: Identify available scripts from package.json, Makefile, or similar
4. **Code Conventions**: Analyze existing code to detect patterns (naming, formatting, etc.)
5. **Key Patterns**: Identify common patterns used in the codebase (error handling, API patterns, etc.)

After analysis, update CLAUDE.md with the findings. Keep existing manual entries and only fill in empty placeholder sections.
