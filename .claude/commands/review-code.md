# Code Review

Review the staged changes (git diff --staged) and provide feedback on:

1. **Code quality**: naming, readability, complexity
2. **Potential bugs**: edge cases, null checks, error handling
3. **Security**: injection risks, exposed secrets, OWASP top 10
4. **Performance**: unnecessary loops, memory leaks, N+1 queries
5. **Tests**: are new features covered by tests?

Provide a summary with actionable suggestions.
